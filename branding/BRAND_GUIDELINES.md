# SurveySync supplied artwork — 9.3.0

The approved master is SurveySync_Logo.jpg, copied byte-for-byte from the supplied 02-3713.jpg. It includes the navy/gold globe, compass star, satellite, SurveySync wordmark and “Unifying Global Data” slogan.

The application header SVG embeds this master with an emblem viewport. The Windows shortcut/installer ICO and FieldBook sidebar PNG are size-format derivatives of its emblem; installer wizard panels use the supplied artwork. The release dialog displays the full master. Client-specific EDSI branding remains separately selectable.

Do not redraw the emblem or replace it with the earlier concept. Executable resource embedding and Windows rendering require the Windows acceptance check; this source candidate does not include rebuilt EXEs.
