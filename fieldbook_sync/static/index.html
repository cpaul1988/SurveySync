STATUS RULE

Primary YES / NO logic

Recommended

Recommended mode keeps the required deliverable simple: exact PointID found = YES; no matching PointID = NO. Dip, pipe, confidence and disagreement checks remain separate QA and never suppress the basic YES/NO result.

SURVEY QC

Derived intelligence

ROD HEIGHT BUST DETECTION

Flags suspicious local elevation jumps near common 0.50, 1.00 and 2.00 project-unit increments when the implied slope is too steep. Designed to catch likely human rod-height/setup mistakes before surface/TIN creation.
