# SurveySync 9.5.0-beta.1 — shared survey workspace

Candidate based on published Stable 9.4.9. Not published or promoted.

Visual Survey QA now provides source visibility, a central project-coordinate map,
linked record selection and an evidence pane. Identify, Pan and Box select are
explicit tools. Multi-selection works without Ctrl and keeps duplicate PointIDs
separate by record UUID. Point-table scopes show all matching, flagged, selected or
visible records; coordinate/source columns can be configured for the session.

Resizable panes support keyboard arrow controls and three presets: Control Review,
Boundary Drafting and Topo QA. Save layout remembers pane sizes on this device.
Narrow windows stack the panels. Layout names do not introduce drafting tools.

A read-only integration inventory reports exact installed package versions and
separates ready, unavailable and planned adapters. No new runtime package is added.
Original evidence, reviewed correction-copy approval, full-scope reports and
stale-project checks remain required. Multi-selection does not bulk-correct elevations.

CAD geometry, drawing/snapping, geographic overview, GNSS and live instruments
remain later phases. See docs/SURVEY_WORKSPACE.md for behavior and limits.
