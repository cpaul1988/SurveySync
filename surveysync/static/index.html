CONTROLSYNC

Control Survey Workspace

0 SHOTS

A simplified TBC-style control workflow: set the project coordinate/local-site system, load the complete survey, inspect observations spatially, then run Ronald's validated three-shot QC across every control.

Project-first workflow: source observations remain immutable. QC evaluates candidate triplets and records exactly which three observations produced each accepted or reshoot result.

1. Project Coordinate System

Choose from the installed coordinate-system library. Local Site settings support modified-ground projects using an explicit grid-to-ground factor, origins and rotation.

NOT SET
Coordinate system not set.

2. Load Control Survey Data

Load CSV/TXT/TSV or Trimble Access JOB/JobXML directly. Delimited files are previewed first: SurveySync detects the delimiter and headers, suggests a column mapping, asks you to confirm ambiguous fields, and can remember the approved mapping for this project. Trimble JOB files are converted with Trimble's installed ASCII File Generator and the original JOB remains immutable source evidence. Labels such as 7A/7B/7C are grouped automatically as Control 7 while the original shot IDs are preserved.

3. Spatial Control Map

All imported observations are plotted in the active project coordinate system. Click a point to focus its control group.

Project Explorer

Control groups and all repeated shots currently stored in this project database.

4. Run Control QC

SurveySync evaluates every 3-shot combination for each control. Passing candidates must clear both horizontal and vertical tolerance. The best passing triplet becomes the active control solution; failed controls receive the next available shot IDs for reshoot.

RON BEST 3

Spatial grouping cross-checks point naming against horizontal and optional vertical proximity. Raw PointIDs are never renamed; probable misnumbers go to the review queue.

Field observation requirements
By default an accepted control must also prove that its three selected shots were taken at least one hour apart, each shot was observed for at least 300 epochs or 5 minutes, and each shot used at least 5 satellites.

Network Least-Squares Adjustment (9.3.2 Beta)
              
Separate conventional-network workflow. Ronald's best-three control method is unchanged. Enter approximate/fixed coordinates and weighted distance/angle observations; SurveySync reports adjusted coordinates, residuals, redundancy, and 95% error ellipses.
